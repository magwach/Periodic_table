**Overview**

A PostgreSQL database to manage and query information about chemical elements in the periodic table.

**Features**

    • Store details about elements, atomic numbers, and properties
    • Query database for specific information
    • Organized schema for efficient lookups

**Setup Instructions**

_Clone the repository:_

    git clone https://github.com/magwach/Periodic_table.git  
    
_Import the database schema into PostgreSQL._

_Use SQL queries to interact with the database._

**Technologies**

    • PostgreSQL
